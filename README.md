## 📖 ABOUT THE WEBSITE

**RED-X ™** is a premium brand website built to showcase music, tech, and community — all wrapped in a dark, gold-accented luxury aesthetic. Every page is hand-crafted with custom animations, immersive interactions, and zero external dependencies beyond font imports and CDN-hosted libraries.

The site consists of **4 interconnected pages**, each with its own distinct visual identity and purpose.

<br />

---

<br />

## 📄 PAGES

<br />

### 🏠 HOME (`index.html`)

The landing page. A **3D particle globe** built with Three.js serves as the hero — 2,500 particles distributed on a Fibonacci sphere with a cyan-to-purple-to-gold gradient. Users can drag to rotate, scroll to zoom, and the globe auto-rotates with momentum on release.

| Feature | Detail |
|---------|--------|
| 3D Particle Globe | Three.js, 2,500 points, Fibonacci distribution |
| Starfield | 800 drifting background stars |
| Orbital Ring | Subtle tilted gold ring rotating around the globe |
| Mouse Interaction | Drag to rotate, scroll to zoom |
| Particle Network | Gold dust particles with connecting lines |
| Glitch Logo | Periodic glitch distortion on the navbar logo |
| Shimmer Buttons | Animated gradient sweep on all buttons |
| Scroll Reveals | Sections fade-slide in via Intersection Observer |
| 3D Card Tilt | Newsletter card tilts with mouse parallax |
| Loading Screen | Animated logo build-up with progress bar |

<br />

---

### 💻 CHANNELS (`channels.html`)

A **cyber-luxe tech aesthetic** page showcasing the three RED-X channels. Circuit board traces, Matrix-style data rain, crosshair cursor, and terminal-style headers create a hacker-meets-luxury feel.

| Feature | Detail |
|---------|--------|
| Circuit Board Background | Animated SVG traces with pulsing gold nodes |
| Data Rain | 25 columns of falling binary and katakana characters |
| Network Graph | Floating gold nodes with connecting lines |
| Crosshair Cursor | Tech crosshair with trailing pixel particles |
| CRT Scan Lines | Subtle scan line overlay across the page |
| Terminal Header | Command-line style title with blinking cursor |
| Tech Cards | Octagon-clipped cards with corner brackets and scan sweep |
| Status Indicators | Green pulsing LIVE/ACTIVE/STREAMING dots |
| 3D Card Tilt | Cards tilt in 3D following the mouse |
| Boot Sequence Loader | Terminal boot log with progress bar |

**Channels Listed:**
- 🎵 **Song Channel** — Lofi, Chill, Remixes, Slowed
- 💬 **Chat Group** — 24/7 community chat
- 💻 **Tech Channel** — Code, Bots, AI, Tutorials

| Feature | Detail |

| Wave Dividers | Layered SVG gold waves between sections |
| Loading Screen | Spinning film-reel rings with RED-X center |

### 📞 CONTACT (`contact.html`)

A **liquid gold glass-morphism** contact portal. Animated SVG blobs with a gooey filter create a molten gold background, while a frosted glass card with gold drips holds the contact CTA.

| Feature | Detail |
|---------|--------|
| Liquid Gold Background | 4 SVG circles with gooey filter, independently animating |
| Glass Card | Frosted glass with backdrop blur and light sweep |
| Gold Drips | 5 animated drips falling from the card top |
| Custom Cursor | Gold ring cursor with trailing particles |
| Floating Orbs | 3 large blurred gold orbs drifting across the screen |
| Liquid Fill Button | Gold gradient rises from bottom on hover |
| Ripple Effect | Material-style ripple on click |
| Contact Chips | Glass pills with hover lift and glow |
| Loading Screen | Dual spinning rings with fade transition |
| 3D Card Tilt | Glass card tilts with mouse parallax |

## ✨ SHARED FEATURES

These elements appear across all pages for a consistent brand experience:

|---------|-------------|

| **Gold/Black Palette** | Consistent use of `#D4AF37` gold, `#000000` black, `#C0C0C0` gray |
